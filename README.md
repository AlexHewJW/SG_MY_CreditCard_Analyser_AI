🚀 **SG_MY_CreditCard_Analyser_AI**

A personal project built to help users analyze month-to-month spending habits across Singapore and Malaysia credit card statements.

Current features:
✅ Automated transaction categorization
✅ Spending trend analysis
✅ Interactive dashboard for expense breakdowns
✅ Support for both Singapore and Malaysian bank statements

Still a work in progress, and I'm currently refining the user interface to make the experience more intuitive and user-friendly.

Next on the roadmap:
🔹 Local data storage and memory-saving mechanisms
🔹 Improved transaction classification accuracy
🔹 Training a lightweight AI model to better recognize local spending patterns and merchant names commonly used by Singapore residents

The goal is to provide a simple and privacy-conscious way for users to understand where their money goes each month.

Feedback and suggestions are always welcome!
